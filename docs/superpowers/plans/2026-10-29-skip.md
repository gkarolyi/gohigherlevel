# Skip Contact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Skip beside Save and next to complete a matching task, create a follow-up three hours from the click, and advance only after verified success.

**Architecture:** Reuse `run` and its existing approved-context, completion-before-creation lane, journal, progress UI, and navigation cleanup. Add an explicit skip mode that bypasses confirmation and selects only task creation; do not duplicate the write pipeline or introduce APIs. Keep the current opportunity validation requirements.

**Tech Stack:** Plain JavaScript userscript, node:test, JSDOM.

**Approved spec:** `docs/superpowers/specs/2026-10-29-skip-design.md`.

## Task 1: Prove Skip behavior with failing tests

- [ ] Append to `tests/concurrent-save.test.cjs`, reusing its harness:

```js
for (const oldTask of [true, false]) {
  test(`Skip postpones follow-up with existing task=${oldTask}`, async t => {
    const h = harness(t, { oldTask });
    h.e("confirmActions = async () => { throw new Error('Skip must not confirm'); }");
    const before = Date.now();
    const pending = h.e("run('skip')");
    for (let i = 0; i < 30; i++) await flush();
    assert.deepEqual(h.writes.map(r => r.operation), [oldTask ? 'complete' : 'task']);
    assert.equal(h.e('__nextCalls'), 0);
    h.gates.complete.resolve();
    for (let i = 0; i < 30; i++) await flush();
    const request = h.writes.find(r => r.operation === 'task');
    assert.ok(request);
    const due = Date.parse(request.body.properties.dueDate);
    assert.ok(due >= before + 3 * 3600000 && due <= Date.now() + 3 * 3600000);
    assert.deepEqual(request.body.owners, ['u1']);
    assert.equal(request.body.properties.title, 'Call again Ada Lee');
    await h.e("run('skip')");
    assert.equal(h.writes.filter(r => r.operation === 'task').length, 1);
    h.gates.task.resolve();
    for (let i = 0; i < 30; i++) await flush();
    assert.equal(h.e('__nextCalls'), 0);
    h.gates.link.resolve();
    await pending;
    assert.deepEqual(h.writes.map(r => r.operation), oldTask ? ['complete', 'task', 'link'] : ['task', 'link']);
    assert.equal(h.e('__nextCalls'), 1);
    assert.equal(h.checkpoint(), null);
  });
}
for (const failure of ['complete', 'task', 'link']) {
  test(`Skip stays on contact after ${failure} failure`, async t => {
    const h = harness(t);
    for (const [operation, gate] of Object.entries(h.gates)) gate.resolve(operation === failure ? new Error('Save failed') : undefined);
    await h.e("run('skip')");
    assert.equal(h.e('__nextCalls'), 0);
    assert.ok(h.checkpoint());
    assert.match(h.w.document.body.textContent, /Save failed/);
    if (failure === 'complete') assert.equal(h.writes.some(r => r.operation === 'task'), false);
    assert.equal(h.writes.some(r => ['stage', 'note'].includes(r.operation)), false);
  });
}
```
